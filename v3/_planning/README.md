# Range Global Education V3 Planning

## Purpose

This folder is the clean planning workspace for the third Range Global Education website direction.

V3 must be planned and built from `RGE Website contents (1).docx` only. Do not copy content, page structure, programme data, testimonials, country claims, partner claims, or wording from old demos or the old website.

## Source Of Truth

- Source document: `../../RGE Website contents (1).docx`
- Allowed content source: the DOCX only
- Old demos: reference only for technical lessons, not for copy or information

## Files

- `sitemap.md`: full site map based on the DOCX page list
- `blueprint.md`: page-by-page professional section blueprint
- `wireframes.md`: low-fidelity page wireframes and layout notes
- `missing-content.md`: content not available in the DOCX and waiting on client confirmation

## V3 Direction

V3 should be organized, professional, and scalable. It should treat Range Global Education as a university partnership and student pathway organization, not a generic study-abroad agency.

The site should emphasize:

- Empowering Through Education
- Education Beyond Borders
- Direct university collaborations
- Structured student application journey
- Global reach through approved destinations and authorised recruitment partnerships

## Design System (as built)

- Primary color: `#D10B20` — the confirmed Range Global brand red. (The earlier
  `#1A56DB` note in this file was the generic placeholder and is superseded;
  the brand guidelines PDF and the official logo files both use the red.)
- Typography: Anton for display/headings, Poppins for body
- Logo: `logo/website logo/` — colour lockup in the header, white knockout in the footer
- Layout: professional, mobile-first, clean corporate structure
- Buttons: one consistent button system for all pages
- Spacing: consistent 8px-based layout rhythm

## Hero Direction

Home uses the **V1 hero treatment**: full-bleed dark image panel, bottom-aligned
copy, world-map and RB-mark watermarks. Unlike V2, there is **no logo inside the
hero** — the logo lives only in the header.
