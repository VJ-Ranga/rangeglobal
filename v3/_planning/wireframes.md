# V3 Wireframes

These are low-fidelity structural wireframes only. They define page hierarchy and content placement before visual design or HTML build.

## Design System Wireframe Rules

- Use consistent header and footer across every page.
- Keep primary content width controlled and readable.
- Use two-column layouts only where comparison is meaningful.
- Use the 10-step service journey as an actual ordered sequence.
- Do not create detailed content cards for pages where the DOCX gives only page names.

## Mobile Wireframe Rule

On mobile, every two-column section stacks in this order:

1. Section heading
2. Primary explanatory copy
3. Cards or list items
4. CTA

The header becomes a simple logo + menu button. The Resources group becomes a stacked link list.
